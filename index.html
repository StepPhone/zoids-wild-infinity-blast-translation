Zoids Wild Infinity Blast - English Translation

Version 1.0.0 · Title ID 0100BF9011CBE000 · Japanese base game (v0) required

Translates the menus, battle text and UI of Zoids Wild Infinity Blast into English. The start logo is also replaced. The mod does not include the game itself - you need your own copy.

Nintendo Switch (Atmosphere CFW)

Download for Switch

  1. Unzip the file and copy the atmosphere folder to the root of your SD card, merging with the existing folder.
  2. The result should be /atmosphere/contents/0100BF9011CBE000/romfs/...
  3. Eject the SD card and start the game.

To remove, delete /atmosphere/contents/0100BF9011CBE000/ from the SD card.

Eden emulator (PC)

Download for Eden

  1. In Eden, right-click the game and choose Open Mod Data Location.
  2. Unzip the file and copy the atmosphere folder into that location, merging with the existing one.
  3. Restart Eden. Go to Configure Game → Add-Ons and tick ZWI_English_Translation.
  4. Launch the game.

Checksums

Verify your download against SHA256SUMS.txt:

sha256sum -c SHA256SUMS.txt
Known limitations
  • Only the Japanese v0 base game is supported. Other versions may crash.
  • English text is longer than Japanese, so some UI labels may be cut off.
  • The game font may not cover every English character.
