Zoids Wild Infinity Blast - English Translation

Version 1.0.0 · Title ID 0100BF9011CBE000 · Japanese base game (v0) required

This is an English localization overlay for Zoids Wild Infinity Blast (JPN). It replaces the start logo with a full-screen StepHackerZ start screen and translates menu and interface text. The mod does not include the game. You need your own copy of the Japanese base game.

Downloads

Download the ZIP for your platform. Both ZIPs contain the same mod files. The only difference is the install instructions inside each one.

Install on Eden (PC)

  1. In Eden, right-click Zoids Wild Infinity Blast and choose Open Mod Data Location.
  2. Unzip the Eden ZIP. Copy the atmosphere folder into the folder that opened, merging with any existing atmosphere folder.
  3. Restart Eden. Right-click the game, choose Configure Game, open the Add-Ons tab and tick ZWI_English_Translation.
  4. Launch the game.

Install on Nintendo Switch (Atmosphère)

Requires Atmosphère custom firmware and the Japanese base game (v0). Not for the v65536 update alone.

  1. Back up your save data before you start.
  2. Unzip the Switch ZIP. Copy the atmosphere folder to the root of your SD card, merging with the existing folder.
  3. The result should be /atmosphere/contents/0100BF9011CBE000/romfs/...
  4. Safely eject the SD card, insert it into the Switch and launch the game.

Update or uninstall

  • Eden: untick ZWI_English_Translation in Add-Ons, or delete atmosphere/contents/0100BF9011CBE000/romfs/ from the mod folder.
  • Switch: delete /atmosphere/contents/0100BF9011CBE000/ from the SD card.

To update, close the game, delete the old files and install the new ZIP. Do not enable two versions together.

What's translated

  • Start logo: StepHackerZ start screen
  • Main menu and title screen
  • Character select
  • Common interface text, custom menu, friends and mission text
  • Boot text

Battle text is not included in this release.

Test status and known issues

  • Not yet tested in Eden or on physical Switch hardware.
  • Not all screens have been playtested. English text is often longer than Japanese, so some text may be cut off or overflow its box.
  • Battle text is not translated in this release.

This release does not establish that every screen is translated or free of overflow. Please report problems with a screenshot, your game version, emulator or hardware, and the steps to reproduce them.
